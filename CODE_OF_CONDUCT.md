# Code of conduct

Be decent. Assume the other person is arguing in good faith and knows something
you do not.

Concretely, for this project:

- **Disagree about the substance.** "That statistic is computed wrong, here is
  why" is welcome and is how most of this project got better. "That is stupid"
  is not.
- **Cite things.** This is a project about not fooling yourself. A claim with a
  source behind it carries; an assertion does not.
- **No investment advice, no promotion.** Do not use the issue tracker to pitch
  a fund, a signal service, a token, or a strategy you are selling.
- **Nothing about a person's identity is on topic here.** Harassment,
  discriminatory language, and personal attacks get the comment removed and,
  if repeated, the account blocked.

If something needs attention, open a private security advisory or contact the
maintainer directly rather than escalating in a thread.
